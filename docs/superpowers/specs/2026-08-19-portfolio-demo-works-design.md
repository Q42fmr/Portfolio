# Демо-роботи для портфоліо — дизайн

Дата: 2026-08-19
Статус: затверджено користувачем (варіант A)

## Мета

Замінити заглушки в портфоліо реальними інтерактивними демо-проєктами, що імітують
комерційні роботи (робота під NDA — публікувати реальні проєкти не можна).
Кожне демо — самодостатнє, з власним брендингом, чесно позначене як «Демо-проєкт».

## Склад робіт (6 демо)

### 1. «Verde» — онлайн-магазин кімнатних рослин (Vue 3 + Vite)

- **Source:** `apps/plant-shop/` (package.json, vite.config.js з `base: './'`,
  `outDir` → `../../portfolio/plant-shop/`). Build-артефакт комітиться.
- **Served:** `portfolio/plant-shop/`
- **Функціонал:** hero; каталог ~12 товарів (grid); фільтри — категорія
  (усі / великі рослини / сукуленти / квітучі / аксесуари), пошук за назвою,
  сортування (ціна ↑↓, назва), діапазон ціни; картка товару в модалі
  (опис, догляд); кошик-drawer: додати / змінити кількість / видалити, підсумок,
  persist у localStorage; checkout-форма з клієнтською валідацією
  (ім'я, телефон, email, адреса) та success-станом без бекенда.
- **Візуал:** товари — інлайн SVG-ілюстрації (листя/горщики), ціни в грн.
  Палітра: зелена/кремова, шрифт з Google Fonts.

### 2. «Pulse» — SaaS-лендінг (сервіс аналітики для малого бізнесу)

- **Served:** `portfolio/saas-landing/` (static: index.html + локальні css/js)
- **Секції:** navbar із мобільним меню; hero з CSS-мокапом дашборда;
  «нам довіряють» (текстові лого); 6 features; how-it-works (3 кроки);
  pricing — 3 плани з перемикачем місяць/рік (−20 %); відгуки; FAQ-акордеон;
  CTA з email-формою; footer.
- **JS:** перемикач цін, акордеон, scroll-reveal через IntersectionObserver.
- **Палітра:** світла, індиго/фіолет.

### 3. «KAVA Roasters» — лендінг кав'ярні-обсмажувальні

- **Served:** `portfolio/coffee-landing/`
- **Секції:** hero; про нас; меню з табами (кава / десерти / зерно на вагу);
  галерея (SVG/CSS-арт); відгуки; години роботи + адреса + мапа-плейсхолдер;
  форма бронювання столика з валідацією; footer.
- **Палітра:** тепла коричнева/кремова, serif-акценти.

### 4. «Anna Kovalenko» — сайт-портфоліо фотографа

- **Served:** `portfolio/photographer-portfolio/`
- **Секції:** hero; галерея masonry із фільтром за жанром
  (весілля / портрет / стріт / природа) та lightbox (←/→/Esc); про мене;
  послуги + 3 пакети цін; відгуки; контакт-форма; footer.
- **Фото:** seeded-URL picsum.photos + lazy loading; сірий bg-fallback,
  якщо зображення не завантажилось. Це єдина зовнішня фото-залежність у наборі.
- **Палітра:** мінімалістична чорно-біла, serif.

### 5. «Flow» — сайт студії танцю

- **Served:** `portfolio/dance-studio/`
- **Секції:** hero; напрямки (hip-hop, contemporary, high heels, breaking, kids);
  інтерактивний тижневий розклад (пн–нд) з фільтром за стилем і рівнем —
  дані в JS-масиві; 4 тренери; абонементи (разове / 8 занять / безліміт);
  форма запису на пробне заняття (стиль, ім'я, телефон); FAQ; footer.
- **Палітра:** темна з неоново-рожевим/фіолетовим, енергійна.

### 6. «Insight» — BI-дашборд (від виконавця; грає на analyst-бекграунд)

- **Served:** `portfolio/analytics-dashboard/`
- **Layout:** sidebar + topbar; KPI-ряд (дохід, замовлення, конверсія,
  середній чек — із дельтами до попереднього періоду); line chart (динаміка
  доходу), bar chart (продажі за категоріями), donut (канали); таблиця
  транзакцій із сортуванням за колонками, пошуком і клієнтською пагінацією.
- **Дані:** детермінований згенерований JS-масив; перемикач періоду
  7/30/90 днів перераховує KPI та графіки.
- **Стек:** static + Chart.js v4 через CDN. Dark UI.

## Технічні рамки

- Статичні демо: один `index.html` + локальні `style.css`/`app.js` на демо;
  Tailwind CDN (як у решті сайту) + власні стилі.
- Зовнішні залежності: Tailwind CDN, Google Fonts, Chart.js CDN (лише дашборд),
  picsum.photos (лише фотограф). Жодних інших.
- Кожне демо: у футері позначка «Демо-проєкт для портфоліо» + посилання
  назад на `../../index.html#projects`.
- Уся контентна мова демо — українська. Без вигаданих реальних клієнтів.

## Інтеграція в портфоліо

- **Дані карток** (`assets/js/main.js`, `PROJECTS_UA`/`PROJECTS_EN`):
  7 записів — Assistant + 6 нових. Розширення моделі:
  `{ title, description, stack[], process, siteUrl, githubUrl|null, imageDesktop, imageMobile }`.
- **Рендер:** `renderProjects()` показує реальні скріни (desktop + mobile колаж)
  замість абстрактних блоків; fallback на старий вигляд, якщо зображення відсутні.
  Модалка ховає кнопку GitHub, коли `githubUrl` порожній.
- **Скріншоти:** кожне демо (і Assistant) — desktop 1280×800 і mobile 390×844 →
  `assets/img/projects/<slug>-desktop.png` / `<slug>-mobile.png` (стиснуті).
- **Видалення стабів:** `portfolio/ecommerce-landing/`, `portfolio/portfolio-template/`,
  `projects/ecommerce-landing.html`, `projects/portfolio-template.html`;
  перевірити й вичистити аналогічні файли/посилання в `en/`.
- **Фейкові GitHub-лінки** (`github.com/your-username/...`) прибрати.
  Реальні додаються пізніше, коли користувач дасть URL репозиторію.
- **EN-версія:** `en/index.html` використовує спільний `main.js` —
  оновити `PROJECTS_EN` (описи англійською; самі демо — україномовні).

## Git-процес

Робота в гілці `stage` (реліз-процес користувача: stage → перевірка → main).

## Верифікація

- Відкрити кожне демо в браузері: проклацати кошик, фільтри, розклад,
  таби, акордеони, графіки, форми (валідація + success-стан).
- Перевірити мобільний viewport (390×844) кожного демо.
- Головна UA і EN: картки з новими скрінами, модалки, посилання на демо працюють.
- `apps/plant-shop`: `npm run build` відпрацьовує, білд відкривається
  за відносним шляхом без сервера-специфіки.

## Ризики

- picsum.photos офлайн → сірі плейсхолдери (передбачено fallback).
- Vite `outDir` поза root → `emptyOutDir: true` і перевірка відносних шляхів.
- Вага PNG-скрінів → стискати (target ≤ 150 КБ на зображення).
