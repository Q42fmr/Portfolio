# KAVA Roasters — сайт кавʼярні-обсмажувальні

Концептуальний сайт вигаданої кавʼярні та обсмажувальні «KAVA Roasters»
у центрі Києва. Проєкт зроблений для портфоліо — такої кавʼярні не існує.

## Сторінки

- `index.html` — головна: хіро з фото, тизер «Про нас», шість позицій меню
  з фото, галерея (6 фото), відгуки, короткі контакти та CTA на бронювання.
- `menu.html` — повне меню з табами «Кава / Десерти / Зерно на вагу» та фото
  кожної позиції.
- `about.html` — історія обсмажувальні, три кроки процесу обсмаження, команда
  (фото без облич — руки, спина, за машиною).
- `contact.html` — адреса, години роботи, схематична CSS-мапа та форма
  бронювання столика з валідацією.
- `credits.html` — повний перелік фотографій з авторами, ліцензіями та
  посиланнями на джерело (Wikimedia Commons).
- `404.html` — сторінка «не знайдено».

```
    ├── img/            — фотографії (15 файлів, ліцензії у credits.json)

```

## Як запустити

Статичний сайт без збірки. Будь-який варіант:

```bash
npx serve .
```

або просто відкрити `index.html` у браузері.

## Стек

HTML + Tailwind CSS (CDN) + ванільний JavaScript (ES2015 класи, без збірки
та залежностей). Доступність: skip-link, ролі ARIA для табів і форми,
фокус-менеджмент при успішному бронюванні, підтримка `prefers-reduced-motion`.

## Фото

Усі фотографії — з Wikimedia Commons за вільними ліцензіями
(CC0, CC BY 2.0, CC BY-SA 3.0/4.0, Public domain). Повний перелік авторів
і посилань на джерела — на сторінці `credits.html` (обовʼязково для CC BY /
CC BY-SA).

## Примітка

Це навчальний/демонстраційний проєкт для портфоліо. Назва, адреса, меню
та відгуки — вигадані.
