# Insight — BI-дашборд аналітики продажів

Концептуальний демо-проєкт для портфоліо: інтерактивний BI-дашборд з KPI, графіками продажів
(Chart.js), таблицею транзакцій із пошуком, сортуванням, фільтром і експортом у CSV, каталогом
товарів і базою клієнтів. Усі дані — детерміновано згенеровані (той самий сид на кожній
сторінці), реальних продажів чи клієнтів не існує.

## Сторінки

- `index.html` — огляд: KPI (дохід, замовлення, середній чек, конверсія), графіки доходу за
  днями/категоріями/каналами, останні 10 транзакцій з посиланням на повну таблицю.
- `transactions.html` — повна таблиця транзакцій: пошук за клієнтом/ID, сортування за будь-якою
  колонкою, фільтр за статусом, пагінація, кнопка «CSV» (завантажує відфільтровані рядки).
- `products.html` — каталог із 8 товарів (фото, категорія, ціна, продано, дохід).
- `customers.html` — клієнти: місто, кількість замовлень, LTV, останнє замовлення.
- `settings.html` — профіль аналітика, команда, перемикачі сповіщень (статично, без збереження).
- `login.html` — статична форма входу, переходить на `index.html`.
- `credits.html` — автори та ліцензії всіх фотографій.
- `404.html` — сторінка «не знайдено».

```
    ├── js/

    ├── img/            — фото товарів та фон сторінки входу

```

## Як запустити

Статичний сайт без збірки: відкрити `index.html` у браузері або підняти локальний сервер,
наприклад `npx serve .`, і перейти на надруковану адресу.

## Стек

HTML, Tailwind CSS (CDN), ванільний JavaScript (ES-модулі не використовуються, усе — звичайні
`<script>` з `window.Insight*` неймспейсами), Chart.js 4.

## Дані та детермінованість

Усі транзакції, товари й клієнти генеруються функцією `mulberry32` з фіксованим сідом, тому
числа на всіх сторінках узгоджені між собою та не змінюються між перезавантаженнями.
