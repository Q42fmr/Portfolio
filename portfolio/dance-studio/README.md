# Flow — студія танцю

Концептуальний сайт студії танцю у Києві. Проєкт створено для портфоліо як демонстрація
багатосторінкового статичного сайту з інтерактивними елементами на чистому JavaScript.

## Сторінки

- `index.html` — головна: хіро з фото, 5 напрямків, «чому ми», заклик на пробне заняття
- `classes.html` — докладний опис кожного з 5 напрямків (рівні, тренер, що взяти)
- `schedule.html` — інтерактивний тижневий розклад з фільтрами за стилем і рівнем
- `trainers.html` — команда з 4 тренерів
- `pricing.html` — абонементи та відповіді на часті питання (акордеон)
- `contact.html` — адреса, графік і форма запису на пробне заняття
- `credits.html` — автори та ліцензії всіх фотографій
- `404.html` — сторінка «не знайдено»

## Структура

```
dance-studio/
├── index.html, classes.html, schedule.html, trainers.html,
│   pricing.html, contact.html, credits.html, 404.html
├── robots.txt, sitemap.xml, site.webmanifest
├── README.md
└── assets/
    ├── css/main.css          — усі стилі поверх Tailwind CDN
    ├── js/
    │   ├── schedule-data.js  — дані розкладу, кольори стилів, регулярка телефону
    │   └── main.js           — рендер розкладу, фільтри, меню, акордеон, валідація форми
    ├── img/                  — фото (JPEG), favicon.svg, apple-touch-icon.png
    └── credits.json          — машинозчитний перелік фото для credits.html
```

## Як запустити

Статичні файли, бекенд не потрібен:

```
npx serve .
```

або просто відкрити `index.html` у браузері.

## Стек

HTML, Tailwind CSS (CDN) + невеликий шар кастомних стилів, ванільний JavaScript
(делегування подій через `data-action`, без фреймворків і збірки).

## Інтерактивність

- Розклад: фільтри за стилем/рівнем, рендериться з `schedule-data.js`; посилання з
  `index.html`/`classes.html` передають напрямок через `?style=` і одразу фільтрують таблицю.
- Форма запису на пробне (`contact.html`): валідація імені й телефону, стан успіху,
  підставляє напрямок з `?style=`.
- Акордеон FAQ (`pricing.html`), бургер-меню на мобільних, плавний скрол.

## Фото

Усі зображення — з Wikimedia Commons за вільними ліцензіями (CC BY, CC BY-SA, Public
Domain). Повний перелік авторів, ліцензій і джерел — на сторінці `credits.html` та у
файлі `assets/credits.json`.

## Примітка

Це навчальний демо-проєкт для портфоліо, а не сайт реальної студії танцю. Усі імена
тренерів, адреса й контакти вигадані.
