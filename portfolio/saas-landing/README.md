# Pulse — лендінг SaaS-сервісу аналітики продажів

Концептуальний проєкт для портфоліо: багатосторінковий маркетинговий сайт
вигаданого сервісу **Pulse**, який допомагає малому бізнесу бачити аналітику
продажів без таблиць і аналітиків у штаті. Домен `https://pulse-analytics.ua/`
вигаданий і реального сервісу не існує.

## Сторінки

- `index.html` — головна: хіро з реальним скриншотом продукту, короткий огляд
  можливостей, «як це працює», тарифи (тизер), відгуки, форма заявки на демо
- `features.html` — 6 можливостей, кожна зі скриншотом фрагмента дашборда
- `pricing.html` — тарифи з перемикачем «Щомісяця / Щороку», таблиця
  порівняння можливостей, FAQ-акордеон
- `customers.html` — 3 кейси використання: кав'ярня, магазин одягу, гуртовий склад
- `about.html` — місія, команда (аватари з ініціалами), контакти
- `legal/privacy.html`, `legal/terms.html` — політика конфіденційності й умови використання
- `credits.html` — автори та ліцензії всіх фотографій і скриншотів
- `404.html` — сторінка «не знайдено»

## Структура

```
saas-landing/
├── index.html, features.html, pricing.html, customers.html, about.html
├── credits.html, 404.html
├── legal/
│   ├── privacy.html
│   └── terms.html
├── assets/
│   ├── css/main.css       — фірмові стилі поверх Tailwind CDN
│   ├── js/main.js         — меню, плавний скрол, перемикач тарифів,
│   │                         FAQ-акордеон, reveal-анімації, форма демо
│   ├── img/                — фото (ліцензовані) + скриншоти продукту
│   └── credits.json        — машиночитані дані про ліцензії фото
├── favicon.svg, apple-touch-icon.png, site.webmanifest
├── robots.txt, sitemap.xml
└── README.md
```

## Як запустити

Статичний сайт без збірки — достатньо будь-якого HTTP-сервера в цій теці,
наприклад:

```
npx serve .
```

або відкрити `index.html` напряму в браузері.

## Стек

HTML5 + Tailwind CSS (через CDN) + ванільний JavaScript (`assets/js/main.js`,
без фреймворків і збірки). Інтерактив: мобільне меню, плавний скрол до
анкорів, перемикач періоду оплати на `pricing.html`, FAQ-акордеон, reveal-
анімації при скролі, валідація форми заявки на демо.

## Фото і скриншоти

- `assets/img/case-*.jpg` — фотографії кав'ярні, магазину одягу та складу з
  Wikimedia Commons, ліцензії CC BY-SA 3.0/4.0. Повний перелік авторів і
  посилань — на сторінці `credits.html` та в `assets/credits.json`.
- `assets/img/app-*.jpg` і `assets/img/feature-*.jpg` — власні знімки екрана
  сусіднього демо-проєкту портфоліо `portfolio/analytics-dashboard`
  («Insight»), використані як ілюстрація продукту Pulse. Окрема ліцензія не
  потрібна — це той самий автор, той самий портфоліо-репозиторій.

## Статус

Навчальний («концептуальний») проєкт без реального бізнесу — створено
виключно для демонстрації навичок верстки та інтерактиву в портфоліо.
